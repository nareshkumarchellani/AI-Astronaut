# 🚀 AI Astronaut

Autonomous AI Space Mission Assistant.

AI Astronaut is a simulated Mars mission-control system that monitors telemetry, detects anomalies, assesses risks, and generates AI-powered mission recommendations using Groq and Streamlit.

## Features

- 🚀 Mars mission simulation
- 📡 Live telemetry
- 🤖 AI rover control
- 🌌 3D Mars digital twin
- 🚨 Emergency scenarios
- 🧠 AI mission analysis
- 📋 Mission event logs
- 💬 AI Astronaut chat
- ⚠️ Anomaly detection
- 🛰️ Orbiter simulation

## Technology

- Python
- Streamlit
- Groq API
- Plotly
- NumPy
- Pandas

This project is a simulation and does not control real spacecraft.
